# Assets

Estructura prevista (Fase 2 en adelante):

- `icons/` — un icono por modulo y por categoria (32x32 y 64x64, linea/relleno propios)
- `fonts/` — tipografia propia
- `cosmetics/` — capas/gorros (Fase 6)

Los iconos se empaquetaran como recursos embebidos en la DLL. No se copian
recursos de Mojang ni de otros clientes.
