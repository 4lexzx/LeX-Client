# Modulo de prueba C++ (Fase 1)

`TestModule.{h,cpp}` exercise los seis tipos de Setting, el ciclo de vida y el
autorregistro con `LEX_REGISTER_MODULE`. Es el unico modulo C++ de esta fase.

Los modulos reales (HUD, Visual, Utilidad) llegan en Fases 3-5, siempre bajo
`modules/hud`, `modules/visual` y `modules/utility`.

Regla: ningun modulo de este proyecto puede dar ventaja competitiva ni
interactuar con anticheats. Solo calidad de vida, informacion y estetica.
